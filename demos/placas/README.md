# Montes / Objetos de conexão

Fonte da demo publicada em ../../sistemas/placas/.

Execute npm ci, npm test e npm run build. Copie dist/ para sistemas/placas/ após validar. Preserva destinos relativos e QR para hospedagem em subdiretórios.

React, TypeScript e Vite; QR gerado com qrcode (MIT). Fontes do sistema. Arte vetorial própria baseada no kit CC0-1.0. Projeto demonstrativo, sem cobrança ou pedido comercial.
